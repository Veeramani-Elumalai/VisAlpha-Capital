## 🌟 Overview

**VisAlpha Capital** is a full-stack FinTech platform that empowers investors with institutional-grade analytics. It combines real-time market data, AI-driven insights, and a modern UI to help users make smarter investment decisions — all in one place.

> *Analyze smarter. Invest better. Grow faster.*

🌐 **Live App:** [https://visalpha-capital.vercel.app](https://visalpha-capital.vercel.app)

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 📊 **Portfolio Dashboard** | Track P&L, day change, sector allocation & benchmark performance vs S&P 500 |
| 🔍 **Stock Screener** | Deep-dive into any stock — PE, ROE, Debt/Equity, Revenue & Profit CAGR |
| 🤖 **AI Stock Advisor** | Rule-based scoring engine delivers **BUY / HOLD / AVOID** verdicts with detailed catalysts |
| 📰 **Daily AI Report** | Personalized morning briefing — news + portfolio analysis generated by **Groq Llama 3** |
| 🏭 **Sector Analysis** | Scan all 11 market sectors with live top performers and key metrics |
| ⚖️ **Stock Comparator** | Side-by-side financial comparison of multiple stocks |
| 📡 **Market News** | Aggregated financial news from NewsAPI across multiple categories |
| 🔐 **Auth System** | Secure JWT authentication + **Google OAuth 2.0** sign-in |

## 🏗️ Architecture

VisAlpha Capital follows a **microservices architecture** with three independently deployable services:

```
VisAlpha-Capital/
│
├── 📁 client/              # React 19 SPA (Frontend)
│   ├── src/
│   │   ├── pages/          # Dashboard, Screener, Advisor, DailyReport, etc.
│   │   ├── components/     # Shared UI components (Charts, Screener, etc.)
│   │   └── services/       # Axios API service layer
│   └── package.json
│
├── 📁 server/              # Node.js / Express (Backend API)
│   ├── src/
│   │   ├── routes/         # auth, portfolio, stock, screener, sector, news, daily-report
│   │   ├── models/         # Mongoose: User, Portfolio, DailyReport
│   │   ├── services/       # Daily Report scheduler + Groq AI orchestration
│   │   ├── middleware/      # JWT auth middleware
│   │   ├── controllers/    # Business logic
│   │   └── utils/          # Market service proxy helpers
│   └── server.js
│
└── 📁 market-service/      # Python / FastAPI (Market Data Microservice)
    ├── main.py             # REST endpoints: /price, /history, /screener, /sector, /advisor
    ├── Services/
    │   ├── screener.py     # yfinance financials + CAGR calculation
    │   ├── advisor.py      # Deterministic scoring engine (BUY/HOLD/AVOID)
    │   ├── sector_setup.py # 11-sector market sweep with ThreadPoolExecutor
    │   └── cagr.py         # CAGR utility functions
    └── requirements.txt
```

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18+
- **Python** 3.9+
- **MongoDB Atlas** account (or local MongoDB)
- API keys for: **Groq**, **NewsAPI**, **Google OAuth**

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Veeramani-Elumalai/VisAlpha-Capital.git
cd VisAlpha-Capital
```

---

### 2️⃣ Setup the Market Service (Python)

```bash
cd market-service

# Create and activate virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Start the service
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

> Market service runs at **http://localhost:8000**

---

### 3️⃣ Setup the Backend Server (Node.js)

```bash
cd server

# Install dependencies
npm install

# Create environment file
cp .env.example .env
# Fill in your credentials (see Environment Variables section)

# Start in development mode
npm run dev
```

> Backend API runs at **http://localhost:5000**

---

### 4️⃣ Setup the Frontend Client (React)

```bash
cd client

# Install dependencies
npm install

# Start the development server
npm start
```

> Frontend runs at **http://localhost:3000**

---

## ⚙️ Environment Variables

Create a `.env` file in the `server/` directory:

```env
# Database
MONGO_URI=mongodb+srv://<user>:<password>@cluster.mongodb.net/?appName=visalpha

# Authentication
JWT_SECRET=your_jwt_secret_key
GOOGLE_CLIENT_ID=your_google_oauth_client_id

# Services
MARKET_SERVICE_URL=http://localhost:8000

# External APIs
GROQ_API_KEY=your_groq_api_key
NEWS_API_KEY=your_newsapi_key

# Server
PORT=5000
```

> ⚠️ **Never commit your `.env` file to version control.** It is already listed in `.gitignore`.

## 📡 API Reference

### Auth Routes — `/api/auth`
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/register` | Register a new user |
| `POST` | `/login` | Login with email & password |
| `POST` | `/google` | Google OAuth sign-in |

### Portfolio Routes — `/api/portfolio` 🔒
| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Get user portfolio with live P&L |
| `POST` | `/add` | Add / average-up a stock position |

## 🤖 AI Features

### Stock Advisor Engine
The advisor uses a **deterministic rule-based scoring system** that evaluates:

| Metric | Threshold | Score |
|---|---|---|
| Revenue CAGR | > 15% | +3 |
| Revenue CAGR | > 10% | +2 |
| Profit CAGR | > 15% | +3 |
| ROE | > 20% | +3 |
| Debt/Equity | < 0.5 | +1 |
| P/E Ratio | < 15 | +1 |

**Verdict Thresholds:**
- 🟢 **BUY** — Score ≥ 5
- 🟡 **HOLD** — Score ≥ 2
- 🔴 **AVOID** — Score < 2

### Daily Report (Groq Llama 3)
Every day, a **cron job** automatically:
1. Fetches the latest financial news across four categories
2. Retrieves the user's current portfolio holdings
3. Sends a structured prompt to **Groq's Llama 3** model
4. Persists the generated report (one per user, per day) in MongoDB
